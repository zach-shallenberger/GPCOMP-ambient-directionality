H/V curve at one station

How the prediction works: f₀ and the peak height come straight from the H/V curve. The depth uses f₀ = Vs₁/4H with the known soft-layer speed. Buildings have a natural period of about 0.1 s per storey, so those with T ≈ T₀ shake in resonance with the ground. The true values use the real local thickness in the analytic 1D model.

Model. ρutt + ρσut = ∂x(μ∂xu) + ∂z(μ∂zu) + ρf with μ = ρVs², a traction-free surface and absorbing sponges, solved by 2nd-order leapfrog finite differences. 60 noise sources in the rock fire band-limited random noise at the same time. Each station's spectrum is divided by the spectrum of bare rock under the same noise.

Simplification. An SH model has only a horizontal component, so the "H/V" shown is the site-to-rock spectral ratio. Field HVSR divides by the vertical component instead. Both peak near the same f₀ for a strong impedance contrast.
